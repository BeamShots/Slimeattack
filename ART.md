# Artwork in this release

Eternal Expedition adds `expedition-icons.webp`, used directly by the offline expedition entry, return screen, Moonforge, merge runes, guild orders and stardust research. It is a real transparent AI-generated atlas, resized and aligned into eight 320px cells (four columns, two rows). Higher rune ranks use named color variants of its cosmic rune art.

Generated with the built-in image generation tool. Final production prompt:

> Use case: stylized-concept. Asset type: mobile fantasy game UI icon atlas, transparent cutout. Create a precisely arranged 4 columns by 2 rows atlas of eight separate beautiful readable magical objects, each centered inside its equal cell, generous transparent margins, no overlap and no text. Row 1: (1) a small adorable blue winged slime piloting a silver crescent compass; (2) an ornate luminous moonstone anvil with a tiny crystal hammer; (3) a lavender swirling rune stone; (4) a royal emerald rune stone. Row 2: (5) a blazing amber rune stone; (6) a radiant cyan star rune stone; (7) a deep violet cosmic crown rune stone; (8) an elegant celestial gold scroll with a jade wax seal. Detailed painterly pixel fantasy RPG inventory art, sharp chunky silhouettes, silver filigree, moonlit teal and purple glow, matching enchanted forest setting. All eight independent assets on genuinely transparent background. No borders, no letters, no UI mockup.

Earlier AI art retained: the Moonhaven village, moonstone UI frame and village icons; original forest, slime atlases, power icon atlases, realm backgrounds and effects. All referenced files are at the root alongside index.html. No image generation service is called by the game. All audio is synthesized locally through Web Audio.
